# ميزان — النسخة الأونلاين الآمنة

هذه النسخة لا تخزن بيانات العملاء داخل GitHub. البيانات تُحفظ في PostgreSQL، وبيانات الاتصال موجودة في Environment Variables.

## تشغيل محلي

1. انسخ `.env.example` إلى `.env`.
2. ضع `DATABASE_URL` لقاعدة PostgreSQL.
3. ضع `JWT_SECRET` قويًا.
4. نفذ:

```bash
npm install
npm start
```

ثم افتح:
`http://localhost:8080`

الدخول الافتراضي:
- username: `admin`
- password: `admin123`

## مهم

GitHub Pages لا يشغل Node.js/Express. استخدم استضافة Backend تدعم Node.js مع PostgreSQL، ثم اجعل نفس الخدمة تشغل `npm start`.

لا ترفع `.env` أو ملفات Excel أو بيانات العملاء إلى GitHub.

## المزايا

- تسجيل دخول قبل استخدام النظام.
- ملفات الحفظ: رقم الملف + اسم الموكل.
- التوكيلات: رقم الملف + اسم الموكل + رقم التوكيل + جهة التوثيق.
- البيانات مخفية عند فتح الصفحة حتى يتم البحث.
- البحث العام بالاسم/رقم الملف/رقم التوكيل/جهة التوثيق.
- زر البيانات الناقصة.
- استيراد Excel يحفظ كل الصفوف غير الفارغة، حتى المكرر والناقص.
- المكرر يُحسب فقط ولا يمنع الإدخال.
- ترتيب أحدث سجل أولًا.
- ترقيم ملفات التوكيلات يبدأ من 2432.
